# Google Play 비공개 테스트 운영 계획

새 개인 개발자 계정의 프로덕션 액세스를 신청하려면 최소 12명의
테스터가 비공개 테스트에 14일 연속 참여 상태를 유지해야 한다.
중도 이탈에 대비해 15명 이상을 모집한다.

## 인증 승인 전 준비

- [ ] 실제 Android 10 이상 비루팅 기기 1대 준비
- [ ] Play Console 모바일 앱 설치 및 개발자 계정 로그인 준비
- [ ] 테스터 15명 이상의 Google 계정 이메일 확보
- [ ] 테스터에게 설치 링크와 피드백 방법을 전달할 연락 채널 준비
- [ ] 개인정보가 포함되지 않은 테스트용 부모 계정 사용 안내

## 인증 승인 직후 실행 순서

1. Play Console에서 `com.monari.family` 앱을 만든다.
2. 내부 테스트에 `monari-1.0.0-release.aab`를 업로드해 설치를 확인한다.
3. 비공개 테스트 트랙을 만들고 테스터 이메일 목록을 등록한다.
4. 테스터에게 참여 링크를 보내고 참여 완료 여부를 확인한다.
5. 최소 12명이 참여 상태가 된 날짜와 시각을 기록한다.
6. 14일 동안 12명 미만으로 내려가지 않도록 매일 참여 인원을 확인한다.
7. 피드백과 수정 내역을 기록하고 프로덕션 액세스를 신청한다.

## 테스터 핵심 시나리오

- 앱 설치, 실행, 업데이트
- 이메일 또는 Google 로그인
- 아이 등록 및 PIN 설정
- 용돈과 지출 기록
- 저축과 미리 당겨쓰기 요청
- 약속 생성, 아이의 완료 요청, 부모 승인
- 알림 확인
- 아이 통장과 월간 리포트 확인
- 로그아웃 후 재로그인
- 설정 화면의 계정 삭제 안내 확인

실제 계정 삭제 검증은 전용 테스트 계정에서만 수행한다.

## 피드백 질문

- 앱 설치 또는 로그인에 실패했는가?
- 화면 전환이 느리거나 멈춘 곳이 있는가?
- 버튼이나 설명 중 이해하기 어려운 부분이 있는가?
- 아이가 혼자 사용하기 어려운 화면이 있는가?
- 금액, 잔액, 승인 결과가 예상과 다르게 표시되는가?
- 사용 기기 모델과 Android 버전은 무엇인가?

## 프로덕션 액세스 신청 답변 메모

- 테스트 참여자: 가족 금융교육 앱의 실제 사용 대상과 유사한 부모 및 보호자
- 테스트 방식: 설치, 로그인, 가족 설정, 거래 기록, 승인, 아이 모드의 핵심 흐름 검증
- 수집한 피드백: 설치·로그인 문제, 속도, 문구 이해도, 금액 및 승인 결과 정확성
- 피드백 반영 방식: 오류 수정, 사용 흐름 단순화, 안내 문구와 접근성 개선
- 출시 준비 판단: 핵심 흐름 완료, 치명적 오류 없음, 정책 및 데이터 보안 답변 점검 완료

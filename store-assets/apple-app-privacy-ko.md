# Apple App Privacy 응답 초안

## 추적

- 다른 회사의 앱과 웹사이트에서 사용자를 추적함: 아니요
- 광고 목적 데이터 사용: 아니요

## 사용자에게 연결되는 데이터

| Apple 데이터 유형 | 수집 | 목적 |
| --- | --- | --- |
| Contact Info - Name | 예 | 앱 기능, 계정 관리 |
| Contact Info - Email Address | 예 | 앱 기능, 계정 관리 |
| Contact Info - Phone Number | 예 | 선택적 SMS 인증 로그인 |
| Identifiers - User ID | 예 | 인증, 앱 기능 |
| Financial Info - Other Financial Info | 예 | 가족이 입력한 교육용 용돈 기록 제공 |
| User Content - Other User Content | 예 | 약속, 메모, 미리쓰기 목적 제공 |
| Usage Data - Product Interaction | 예 | 약속과 승인 등 앱 기능 제공 |

## 사용자에게 연결되지 않는 데이터

- 없음

## 수집하지 않는 데이터

- 결제 정보
- 신용 정보
- 실제 금융 계좌 정보
- 정확한 위치 또는 대략적 위치
- 연락처
- 사진, 동영상, 오디오
- 건강 및 피트니스 정보
- 검색 기록
- 광고 데이터
- 진단 및 충돌 데이터

## App Store 연령 등급 예상

- 폭력, 성적 콘텐츠, 욕설, 공포, 약물, 도박: 없음
- 사용자 생성 콘텐츠의 공개 공유: 없음
- 실제 금융 거래: 없음
- 부모가 관리하는 아동용 기능 포함

## 심사 참고사항

- 앱의 금액, 이자, 저금 및 미리쓰기는 실제 금융 거래가 아닌 교육용 가족 기록입니다.
- 부모 계정이 아이 프로필과 PIN을 만들고 관리합니다.
- 계정 삭제 기능과 공개 계정 삭제 URL을 제공합니다.

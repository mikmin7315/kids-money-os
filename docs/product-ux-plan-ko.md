# Monari 제품 UX 개선 기획

## 제품 원칙

- 아이 화면은 `오늘 할 일 → 보상 → 내 돈` 순서로 단순하게 구성한다.
- 부모 화면은 `확인할 일 → 아이별 상태 → 관리` 순서로 구성한다.
- 아이와 부모 화면의 정보 및 권한 경계를 명확히 분리한다.
- 첫 화면에는 매일 확인하거나 행동해야 하는 항목만 둔다.

## 속도 기준

- 화면 전환 목표: 1초 이내
- 최초 인증 화면 목표: 2초 이내
- 화면마다 필요한 데이터만 조회하고, 전체 테이블 묶음 조회는 단계적으로 제거한다.
- 거래 및 약속 기록은 페이지네이션하여 데이터 증가에 따른 속도 저하를 방지한다.

## 아이 앱

### 아이 메인에 유지할 항목

1. 현재 사용 가능한 잔액
2. 오늘 약속 진행률과 바로 체크하기
3. 저금하기
4. 최근 거래 3건
5. 연속 약속 달성 기록

### 아이 메인에서 이동할 항목

- 이번 달 상세 통계: 내역 화면으로 이동
- 미리쓰기 요청 폼: 돈 관리 화면으로 이동
- 긴 입력 폼: 전용 화면 또는 바텀 시트로 이동
- 부모용 승인 및 설정 정보: 아이 화면에서 제거

### 아이 하단 메뉴

| 메뉴 | 목적지 | 역할 |
| --- | --- | --- |
| 홈 | `/child/[id]` | 잔액과 오늘 할 일 |
| 약속 | `/child/[id]/promises` | 오늘 약속 체크와 기록 |
| 돈 관리 | `/child/[id]/money` | 저금 및 미리쓰기 |
| 내역 | `/child/[id]/history` | 해당 아이 거래만 표시 |

### 아이 화면 개선 우선순위

1. 앵커 링크 기반 약속·저금 메뉴를 전용 화면으로 분리
2. `/records` 부모 화면 대신 아이 전용 내역 화면 추가
3. 약속 체크 완료 후 즉시 진행률과 보상 상태 표시
4. 저금 목표 기능 추가

## 부모 앱

### 부모 메인에 유지할 항목

1. 승인 대기 건수와 바로 처리하기
2. 아이별 잔액, 저금액, 오늘 약속 상태
3. 최근 가족 금융 활동
4. 빠른 행동: 용돈 지급, 약속 만들기

### 부모 메인에서 줄일 항목

- 의미가 중복되는 월간 요약 카드
- 맥락 없이 숫자만 보여주는 이번 주 활동
- 첫째 아이만 강조하는 단일 대표 잔액

### 부모 하단 메뉴

| 메뉴 | 역할 |
| --- | --- |
| 홈 | 가족 상태 요약 |
| 승인 | 약속 및 미리쓰기 승인, 배지 표시 |
| 약속 | 약속 규칙 생성·관리 |
| 기록 | 거래와 월간 리포트 |
| 설정 | 아이, 용돈, 이자 정책 관리 |

### 부모 화면 개선 우선순위

1. 승인 탭에 대기 건수 배지 추가
2. 다자녀를 동일한 중요도로 보여주는 아이 카드 구성
3. 기록과 리포트를 하나의 정보 구조로 통합
4. 약속 관리와 승인 처리 화면의 역할 분리

## 공통 디자인 기준

- 핵심 행동은 화면당 최대 2개만 강하게 강조한다.
- 금액, 상태, 행동의 시각적 우선순위를 일관되게 유지한다.
- 아이 화면은 친근하지만 금융 정보가 장난처럼 보이지 않게 한다.
- 부모 화면은 빠른 판단을 위해 카드 수를 줄이고 상태 배지를 사용한다.
- 모든 로딩, 빈 상태, 오류 상태에 다음 행동을 명확히 제공한다.

## 구현 로드맵

### 1단계: 핵심 동선

- 아이 전용 약속, 돈 관리, 내역 화면 추가
- 아이 하단 메뉴를 실제 라우트로 전환
- 부모 승인 배지 추가

### 2단계: 부모 홈 재구성

- 중복 지표 제거
- 다자녀 카드와 승인 중심 홈 구성
- 기록·리포트 통합

### 3단계: 데이터 성능

- 화면별 전용 데이터 조회 함수 작성
- 거래 및 약속 기록 페이지네이션
- Supabase 집계 RPC 또는 뷰로 대시보드 계산 이동

### 4단계: 목표와 학습

- 아이 저금 목표
- 이자 학습 화면 연결
- 달성 축하와 부모 피드백 흐름 추가

# Android 실제 기기 출시 점검

## 준비

- Android 10 이상 비루팅 기기
- USB 디버깅 활성화 및 PC 연결 허용
- 서명된 출시 APK
- 스토어 심사용 부모 계정과 아이 PIN

연결된 기기는 정확히 1대만 유지한 뒤 실행한다.

```powershell
npm run smoke:android-device
```

스크립트는 출시 APK 설치, 앱 실행, 네이티브 인증 딥링크 호출을 확인한다.

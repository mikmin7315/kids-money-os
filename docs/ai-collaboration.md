# Codex + Claude Code 협업 원칙

Monari의 후속 작업은 Codex가 구현과 통합을 담당하고, 로컬 Claude Code가 독립 리뷰를 수행하는 방식으로 진행한다.

## 기본 흐름

1. 작업 전 Codex가 현재 변경과 책임 범위를 확인한다.
2. 보안, 인증, 데이터 경계, 출시 영향이 있는 변경은 구현 전 Claude Code에 읽기 전용 리뷰를 요청한다.
3. Codex는 Claude의 제안을 코드 근거와 실제 제약에 맞춰 독립 검증한다.
4. Codex가 필요한 변경을 구현하고 전체 검증을 실행한다.
5. 완료 전 Claude Code에 변경 파일 재검토를 요청한다.

## 역할

- Codex: 구현, 통합, 테스트, 최종 판단
- Claude Code: 독립 리뷰, 누락 탐색, 대안 제안

Claude Code의 제안은 자동 적용하지 않는다. 기존 변경을 되돌리지 않고, 검증된 제안만 현재 코드 구조에 맞게 통합한다.
